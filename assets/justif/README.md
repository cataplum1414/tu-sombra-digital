# Atribución de Justif

El sitio utiliza [Justif 0.9.2](https://github.com/lyallcooper/justif), de Lyall Cooper, bajo licencia MIT. El texto de la licencia se conserva en `LICENSE`.

El archivo `dist/hyphenate/es.js` incorpora los patrones españoles de `hyph-utf8` (versión 5.0, 2019-09-24), de Javier Bezos y CervanTeX, bajo MIT/X11. Referencias: [patrones originales](https://github.com/jbezos/tex-hyphen-spanish) y [licencia](https://opensource.org/licenses/MIT).
